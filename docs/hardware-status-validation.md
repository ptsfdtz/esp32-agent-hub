# 状态显示实机验证（2026-09-05）

设备：COM7，ESP32-S3，MAC `3c:0f:02:d4:b2:8c`。通过真实 MQTT → ESP32 协议解析 → Model → U8g2 绘制链路测试。串口 `q` 读取设备模型；`f` 导出设备 OLED 缓冲，PNG 保存在 `build/hardware-status/`。这不是摄像头拍摄，不能代替面板电气/光学检查。

## 复现及修复

- 校时后额度消失：真实 Bridge 额度消息缺少 `ts`，固件 NTP 校时后的新鲜度校验拒收。实机初始为 `working=1 usage=0`，缓冲显示 `5h -- / week --`。已为额度发送包补当前传输时间，与 `measured_at` 分开。
- 正在工作却看不到状态：旋钮 20 秒无输入触发待机覆盖层，隐藏 Working。工作期间现在禁止覆盖，工作结束后可正常待机。
- 真实会话被判空闲：Windows 上持续写入的日志文件 mtime 可保持不变，之前 5 分钟 mtime 筛选排除了真实任务。现以文件长度追踪追加，以事件中的时间戳判断活跃；首次顺序恢复状态，之后增量读取，避免固定尾部窗口漏掉任务开始。新增固定 mtime 追加完成事件及大文件恢复测试。
